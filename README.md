### 🎲 Mancala AI – Intelligent Game Playing System

Mancala AI is an artificial intelligence project developed to explore and implement classical problem-solving and game-search techniques through the traditional Mancala board game.

The project features multiple game modes, including **Human vs AI** and **AI vs AI**, allowing users to analyze and compare the behavior of different decision-making strategies. Two difficulty levels, **Easy** and **Hard**, were implemented to demonstrate how search depth and evaluation quality influence the performance of intelligent agents.

The AI agents are based on adversarial search algorithms and heuristic evaluation functions. Each game state is analyzed according to strategic criteria such as stone distribution, potential captures, score advantage, extra turns, and board control. The system evaluates the cost and utility of possible moves in order to select the most advantageous action.

#### Key Features

* Human vs AI gameplay
* AI vs AI simulation mode
* Configurable difficulty levels (Easy / Hard)
* Strategic move evaluation using heuristic functions
* State-space exploration and decision-making
* Comparative analysis of different AI strategies
* Interactive game interface

#### Educational Objectives

This project was developed as part of an Artificial Intelligence and Problem Solving course to study how intelligent agents can make optimal decisions in competitive environments. It demonstrates the practical application of search algorithms, heuristic reasoning, and strategy evaluation in turn-based games.
